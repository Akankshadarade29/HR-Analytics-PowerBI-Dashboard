# 📊 HR Analytics Dashboard | Power BI

## 📌 Project Overview

An interactive **HR Analytics Dashboard** developed using **Power BI** to analyze employee attrition, workforce demographics, salary trends, job roles, departments, and job satisfaction.

The dashboard provides key HR metrics and interactive visualizations to identify employee attrition patterns and support data-driven decision-making.

## 🛠️ Tools & Technologies

* **Power BI**
* **Microsoft Excel**
* **Data Cleaning & Transformation**
* **Data Analysis**
* **Data Visualization**

## 📈 Key KPIs

* Total Employees
* Active Employees
* Total Attrition
* Attrition Rate
* Average Age
* Average Monthly Pay

## 🔍 Analysis Performed

* Employee attrition by **age group**
* Attrition by **gender**
* Attrition by **department**
* Attrition by **job role**
* Attrition by **education field**
* Analysis of **job satisfaction**
* Analysis based on **business travel and employee demographics**
* Salary and workforce analysis

## 📊 Dashboard Features

* Interactive KPI cards
* Dynamic charts and visualizations
* Slicers and filters
* Department-wise analysis
* Job role analysis
* Demographic analysis
* Attrition trend analysis
* Interactive employee segmentation
